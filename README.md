2D-игра-Unity
2D-симулятор на Unity, обучающий игроков основам алгоритмов. Управление сделано с помощью блоков-команд, из которых игрок собирает алгоритмы движения и работы роботов.

Технологии:
Unity 6000.4.8f1 и выше
Visual Studio ("Разработка классических приложений .NET" и "Разработка игр с помощью Unity") - для редактирования скриптов

Запуск:
Клонируйте репозиторий. Откройте проект в Unity (совместимо с Unity 6000.4.8f1 и выше). Для изменения игры изучите сцену, скрипты и отредактируйте их.

Демонстрация: 
https://vadim2045.github.io/PracticeUnityProjectWEBGL/

Скрипты:
```
AlgSave.cs - скрипт работы DropZone и выбор роботов.
AllowWADs.cs - для разрешения управления роботами с помощью кнопок W, A, D и пробел.
DraggableElement.cs - для заполнения списка DropZone блоками.
DropAndClick.cs - код DropZone и адаптация интерфейса под мобильные устройства.
InfoScreen.cs - код всплывающих окон.
RobotMovement.cs - код движения роботов, логика работы столов и карты.
```
